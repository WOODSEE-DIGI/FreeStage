Project Manager

When FreeStage launches it shows the Project Manager dashboard. This is where you choose what to work on, just like DaVinci Resolve's project manager.

  • New Theatre Show — cue list, scenes, and layers for live shows, comedy, theatre, and projector-based events.
  • New Presenter Show — segment rundown for person-to-camera work such as news, vlogs, and evidence presentations.
  • Open Show… — browse for any saved .fst show package.
  • Recent Shows — pick from the last 20 shows you opened or saved. FreeStage stores a bookmark for each one so file access survives relaunches.

Hover over a recent show and right-click to remove it from the list. Selecting a show opens the correct workspace for that show's kind.

Show Kinds

FreeStage supports two show systems. The underlying render engine is shared, but the UI and document model are tailored to each workflow.

Theatre / Projector

The original FreeStage workspace: a cue list of scenes, each containing layers. Best for live events where every cue can change the entire canvas.

Presenter to Camera

A streamlined workspace built around a linear segment rundown:

  • Camera + Graphic — presenter camera with a named placeholder overlay (lower third, story graphic, etc.).
  • Video Package — a pre-prepared video file that can auto-advance to the next segment when it ends.
  • Title Card — a full-screen placeholder such as an opening or closing title.
  • Break — black/holding screen.

Segments reference placeholders by name, so the same rundown can be reused with different graphics. Each placeholder can hold an image, text, lower third, or other source. Primary and secondary camera angles are configured once per show in the right-hand Show Setup panel.

The Show Setup > Background picker sets a global background source (image or video) that is rendered behind every presenter segment. Because it is a separate layer, it stays full-frame even when you zoom or reposition the camera layer. Use the segment-level Chroma Key > Background only when you want the background to move with the keyed camera layer.

Show Setup > Global Layers are layers that persist across every presenter segment. Each global layer has a Placement of either Background (rendered behind the presenter and segment placeholders, e.g. a looping video frame) or Foreground (rendered on top, e.g. a logo bug). Add an image, video, or color layer, toggle visibility, rename it, and adjust position, size, opacity, and placement. Placeholders are a different idea: they are named, reusable source slots that a cue references by name, so swapping the placeholder's source updates every cue that uses it.

Cue Layers live in the selected segment's editor and belong to that cue alone — the place to add a one-off Screen Share, image, video, NDI or Syphon feed, or colour matte without disturbing any other cue. Each cue layer has the same Placement control as a global layer: Background composites behind the cue content (after the global background layers), Foreground composites above the cue content but beneath the global foreground layers. Use the eye button to hide a layer without deleting it, and the trash button to remove it from the cue. Because the whole workspace renders one Scene per cue, a cue layer reaches the preview, live output, recording, and stream simultaneously, and screen/NDI captures start automatically when the cue is previewed or taken live.

If a screen-share layer stays black: macOS Screen Recording approval is recorded against the app's code signature. An ad-hoc signed development build gets a new signature on every build, so System Settings can show FreeStage as enabled while the running app is actually denied — the log reports The user declined TCCs for application, window, display capture. Remove FreeStage from System Settings → Privacy & Security → Screen & System Audio Recording with the − button, add it back, and relaunch. The Cue Layers panel shows a warning with Grant Permission… and Retry Capture buttons whenever this is the case.

Title Card segments with no placeholder selected are transparent so the global background shows through. Assign a placeholder to the segment when you want title content to appear.

The presenter Rundown sits on the left. Click any cue to edit it — the list collapses to a tight 84 pt icon strip showing the cue number and type icon, and the expanded editor appears beside it. Click the X in the editor header to return to the full rundown list.

The three main columns — rundown/editor, live/preview monitors, and Show Setup — are laid out with a native AppKit NSSplitView. Drag either divider to resize columns; the dividers are handled by macOS itself, so they track the cursor reliably and do not drift or flicker. Implicit animations are disabled across the workspace so column widths never pulse or flicker.

When a segment is selected, the rundown collapses to a tight 84 pt icon strip and the segment editor opens beside it. The editor defaults to 640 pt wide (minimum 580 pt) so its segmented pickers, sliders, and GroupBoxes have room to breathe. The left column minimum switches automatically between 580 pt when the editor is expanded and 220 pt when the rundown list is shown.

The live/preview monitors use their ideal 16:9 aspect ratio and fill the available centre space. The Show Setup column defaults to 240 pt wide (minimum 200 pt). Each column has a sensible minimum size, and the dividers stop dragging before any panel becomes unusable.

Select any segment to edit its name, type, camera angle, placeholder, video file, Cue Layers, and Auto-follow setting. When Auto-follow is enabled on a Video Package, FreeStage automatically fires the next segment after the trimmed video duration elapses.

While a Video Package is live, the transport bar shows Restart and Play/Pause buttons so you can control playback without opening the Clip Editor.

For Camera + Graphic segments, the segment editor also exposes:

  • Camera Framing — software zoom and pan so you can crop or re-frame the shot per segment without touching the physical camera.
  • Gimbal — pan/tilt target angles and a Send to Gimbal toggle. When the toggle is on, the angle is sent to a connected OBSBOT gimbal each time the segment goes live (or immediately while you drag the sliders).
  • Chroma Key — enable the key, pick a preset (green/blue/custom), adjust hue, threshold, smoothing, edge feather, edge despill, spill suppression/range, and skin-tone protection, and choose a background image or video to composite behind the keyed subject.
  • Cue Layers — add layers that appear in this cue only (screen share, image, video, NDI, Syphon, colour), then set each one's placement, position, size, and opacity. Global layers stay in Show Setup; cue layers travel with the segment.
  • Expandable Editor — click the expand arrow on the selected segment to collapse the rundown into a narrow icon strip and give the segment controls the full left-column height. Click the close button to return to the normal rundown view.

Click Open Clip Editor on a Video Package to scrub the video, mark In and Out points, and export a trimmed Subclip. The timeline shows green and red markers for the In and Out points and highlights the trimmed range. Playback always respects the In/Out range, even before a subclip is exported — exporting is only needed if you want a separate trimmed file on disk. If the source bitrate is high (above 8 Mbps), FreeStage automatically generates a lower-resolution proxy for smooth scrubbing; you can also manually regenerate the proxy at any time.

Workspace Overview

The FreeStage window is divided into four areas:

  • Masthead (top): active cue info on the left, the big GO button on the right, the source toolbar below, and a Stop control that appears while recording.
  • Left pane: the cue list and the inspector for the selected layer.
  • Center/right: Program (live output) and Preview monitors.
  • Right sidebar: Scenes library and Audio mixer.
  • Footer: Edit/Show mode switch, left inspector toggle, masthead toggle, Panic in the center, and the right sidebar toggle on the far right.

Tip: The workspace requires a minimum window size of 1200 × 800. If FreeStage opens smaller than expected, macOS may have restored a previously saved window frame. Resize the window larger or Option-click the green zoom button to reset it.

Edit Mode vs Show Mode

Use the segmented control in the footer to switch modes.

Edit

  • Build and arrange your scenes and cues.
  • GO previews the active cue in the Preview monitor without starting recording or streaming.
  • Layers can be added, moved, scaled, and filtered.

Show

  • Run your production.
  • GO arms recording/streaming and fires the active cue to the live Program output.
  • The virtual camera can be activated automatically if enabled in Settings.

Scenes

A scene is a visual composition made of stacked layers. Scenes live in the Scenes tab of the right sidebar.

  • Click Add to create a new empty scene.
  • Select a scene, then use the source toolbar (Camera, Screen, Color, Text, Slideshow) to add layers to it.
  • Right-click a scene to Add Cue for Scene, Duplicate Scene, or Delete Scene.
  • Deleting a scene also deletes any cues that reference it.

Layer Transforms

Select a layer in the Layer Editor to adjust its position, size, and opacity.

  • X / Y — move the layer center around the canvas (0–1, normalized).
  • Size — scale the layer uniformly. This is the quickest way to zoom a source in or out.
  • Width / Height — scale each axis independently. For image, video, slideshow, NDI, Syphon, and browser sources these act as a bounding box and the source is aspect-fitted inside it so it is never stretched.
  • Opacity — fade the layer.
  • Fit to Canvas — reset position and scale to fill the output. Aspect-ratio sources are still fitted, not stretched.

Sources

Each layer in a scene is backed by a source. FreeStage supports cameras, screen captures, still images, video files, slideshows, browser sources, color fills, text, drawing, template overlays, and shared-memory video feeds.

Syphon Input

FreeStage can receive a live video feed from any Syphon server running on the same Mac. This is useful for pulling output from VJ software, Resolume, TouchDesigner, or another production tool into a FreeStage layer.

  • In the Layer Editor, choose Add Layer → Syphon….
  • The picker shows every Syphon server currently published on the Mac.
  • Select a server and click Add Layer. FreeStage stores the server's unique ID so it reconnects automatically if the server restarts.
  • Transform, chroma key, and filters work on a Syphon layer just like any other source.

NDI Input

FreeStage can also receive NDI sources from the local machine or the local network.

  • In the Layer Editor, choose Add Layer → NDI….
  • The picker shows every NDI source currently visible on the network.
  • Select a source and click Add Layer. FreeStage reconnects by source name.
  • NDI video is decoded to BGRA and can be transformed, keyed, and filtered like any other layer.

Note: NDI input links against the NDI runtime (libndi.dylib) installed on this Mac. The SDK headers are bundled under Vendor/NDI and subject to the NDI SDK license.

Layer Defaults

FreeStage can remember a layer's transform, opacity, blend mode, filters, and camera settings as the default starting point for a source.

  • Configure a layer exactly how you want it (e.g., green-screen chroma key, size, and position).
  • Click Save as Default in the Layer inspector. The button becomes Update Default if one already exists.
  • Whenever you add that same source again — from the Layer Editor or the Add Cue menu — FreeStage applies the saved defaults automatically.
  • Defaults are keyed by source: per camera, per NDI/Syphon source, per file, or per template type.

Cues

A cue points to a scene and advances the live output when fired. Cues are listed in the left-hand cue list.

  • Select a cue to make it the next cue standing by.
  • Right-click a cue to Fire Cue directly, Select as Next, or Duplicate Cue.
  • Duplicate a cue to reuse the same scene in another place in the rundown.
  • Toggle Armed in the inspector to disable a cue. Disarmed cues cannot be fired.
  • Assign a list color to a cue in the inspector. The entire cue row is tinted with one continuous block of color, and a bright color bar appears at the left edge of the cue list so the color is easy to spot.

Saving Shows

Use Cmd S to save your show as a .fst file. FreeStage stores shows as document packages: a folder that looks like a single file in Finder and contains the show JSON plus an Assets/ folder.

  • Save (Cmd S) overwrites the open package. The first time a show is saved, FreeStage asks where it should live.
  • Save As… (Cmd Shift S) always asks for a new location and switches the document to that package.
  • Autosave runs every three minutes and writes the open package only when the show's content actually changed. It never prompts and never creates a file for a show you have not saved yet. Changing the selected cue, scene or panel layout does not count as a change.
  • Every image, video, slideshow image, face-puppet image, chroma-key background, and per-cue layer asset is copied into the package.
  • Shows are fully portable: you can move, rename, copy, or archive the .fst package without losing linked files.
  • The active cue, selected layer/scene, edit/show mode, and panel visibility are also saved and restored.
  • Assets inside a package keep a stable, path-derived name, so repeated autosaves overwrite the existing copy instead of creating duplicates.
  • Older single-file .fst documents can still be opened; saving them again converts them to the new package format.

Note: FreeStage is not sandboxed, so file access is governed by normal macOS permissions rather than security-scoped bookmarks.

GO & STOP

The GO button lives on the top right of the masthead and is the main show control.

  • In Edit mode, GO fires the standing-by cue for preview only.
  • In Show mode, the first GO starts recording (if enabled) and fires the cue to Program.
  • Subsequent GO presses advance to the next cue.
  • Press Space as a shortcut for GO.

Stopping the Show

  • While recording, a red STOP button appears to the left of GO. Press it to stop recording and end the show.
  • Press Esc as a shortcut for STOP.
  • Panic in the footer immediately fades live output and stops recording.

Show Library

FreeStage keeps every asset and every recording inside one show library folder, so a show on a different Mac only needs that folder to come along.

On first launch a setup sheet asks where the library should live (default ~/Movies/FreeStage) and creates this structure:

<library root>/
├── FreeStage Library.md
├── GlobalAssets/
│   ├── LUTs/            Colour lookup tables (.cube)
│   ├── Plugins/         Third-party effect bundles
│   ├── Sound Effects/   Stings, applause, rimshots
│   ├── Music/           Walk-on and backing beds
│   ├── Memes/           Reaction images and clips
│   ├── Logos/           Pre-keyed logos for bugs and lower thirds
│   ├── Images/          Stills, backdrops and backgrounds
│   ├── Videos/          Clips, loops and VT rolls
│   └── Templates/       Imported show styles and template packs
├── Shows/               Saved show packages (.fst)
└── Output/
    ├── Recordings/      Recordings from Cmd Shift R or GO
    └── Exports/         Manual exports and renders
  • The template is additive: FreeStage never deletes or overwrites files in your library. Missing folders are recreated, and a stray file blocking a folder name is reported rather than removed.
  • Each folder gets a short README.md the first time it is created, explaining what belongs there.
  • Change the location any time from Settings → Show Library → Choose…, or from the Show Library row on the Project Manager. The template is created at the new location immediately.
  • Recordings default to Output/Recordings and follow the library when you move it. Choosing a different recording folder in Settings keeps that override until you press Use Library Default.
  • Restore Folder Structure in Settings recreates any folder you deleted by hand.

Recording

FreeStage can record the Program video and mixed audio to disk.

  • Open Settings to choose the recording directory, format (H.264 or HEVC), resolution, frame rate, bitrate, auto-split interval, and minimum free-space guard. By default recordings are saved to Output/Recordings inside your show library.
  • Enable Record on GO to start recording automatically with the first GO in Show mode.
  • Enable Stop recording at show end to finish the file after the last cue fires.
  • Use the Output menu or the STOP button to stop recording manually.
  • In the Audio sidebar you can pause, resume, and split a recording. Pausing finalizes the current file; resuming creates a new one.
  • Reveal the last recording from the Output menu.

Streaming

FreeStage can stream the Program output and mixed audio to RTMP/RTMPS destinations such as Twitch, YouTube, or Facebook Live.

  • Open Settings → Manage Stream Destinations to add your ingest server URL and stream key.
  • Select Twitch, YouTube, Facebook Live, or a custom RTMP server from the platform dropdown.
  • Use the Go Live button in the Audio mixer sidebar to start streaming to an enabled destination.
  • FreeStage displays stream duration and auto-reconnects up to five times if the connection drops.
  • Streaming shares the same Program video and mixed audio that are recorded and sent to the virtual camera.

Note: Live streaming requires the HaishinKit Swift Package to be added to the FreeStage Xcode project. The build succeeds without it, but streaming remains inactive until the package is linked.

Slideshows

A slideshow layer cycles through a folder of still images. Use it as a full-layer source or as the background behind a chroma-keyed camera.

  • Click Slideshow in the source toolbar or Scenes sidebar to choose a folder of images.
  • Set the interval (2–60 seconds), transition style (Cut or Dissolve), and whether to shuffle the order.
  • In the layer inspector you can replace the image folder, change the interval, and preview the first images.
  • As a chroma-key background, a slideshow is treated like any other source: the keyed area reveals the current slide.

Drawing Layer

The Draw source adds an illustration/annotation layer you can paint on directly. Use it for live markup, lower-thirds sketches, or quick overlays.

  • Click Draw in the source toolbar or Scenes sidebar to add a new drawing layer.
  • Select the layer and click Edit Drawing… to open the full-screen editor.
  • Choose the Pen or Eraser, pick a color, and set brush width.
  • Undo individual strokes or clear the whole canvas.
  • The drawing is stored as vector-like strokes, so it scales cleanly when you transform the layer.
  • Tablet pressure is captured for pen strokes when a pressure-sensitive input device is used.

Shapes & Text

In the drawing editor you can switch from freehand pen to precise shapes and text labels.

  • Rectangle / Ellipse — click and drag to define the bounding box.
  • Line / Arrow — click and drag from start to end; Arrow adds a head at the end point.
  • Text — select the Text tool and click where you want the label, then type in the prompt. Text size is controlled by the Size or Width slider.
  • All shapes and text use the current color and line width.

Chroma Key

FreeStage's chroma keyer supports multi-point sampling and fine spill control for tough green/blue screens.

  • Enable: turn on the main Chroma Key switch in the layer inspector. If the green screen stays visible, check that the switch is on and the A/B bypass is off.
  • Key Colors: add up to four sampled colors to handle highlights and shadows across an uneven screen.
  • A / B Bypass: toggle the bypass switch to temporarily disable the key and compare against the original source.
  • Edge Feather: softens the transition between kept and keyed-out pixels.
  • Edge Despill: boosts hue-targeted spill suppression exactly where the foreground meets the keyed background.
  • Spill Suppression / Range: removes the selected key color from foreground edges and skin tones. The spill is subtracted along the actual key hue vector, then a complementary or skin-warm hue is added back.
  • Skin Tone Protection: detects warm skin tones and applies a skin-safe despill that removes green/blue spill from fair skin while keeping it warm, rather than just disabling the correction.
  • Background: choose an image or video to composite behind the keyed layer, or leave it transparent.

Audio Mixer

The Audio tab in the right sidebar controls the live mix.

  • Output Device: choose the device FreeStage monitors to. This changes the system default output.
  • Input Device: choose the microphone or audio interface to capture.
  • Microphone / System Audio: each channel has volume and Low/Mid/High EQ.
  • Master: overall output volume.
  • Mute Output: silence the monitor without affecting the recording.

Tip: Start the audio engine before your show. If you change the input device, capture restarts automatically.

External Control

FreeStage can receive cues from Stream Deck, Bitfocus Companion, TouchOSC, or any HTTP/OSC client.

HTTP Trigger Server

Enable it in Settings → External Control. Default port is 17352.

curl -X POST http://localhost:17352/cue/<uuid>
curl http://localhost:17352/cues

Right-click any cue and choose Copy HTTP Trigger URL to get its exact address.

OSC Trigger Server

Enable it in Settings → External Control. Default port is 17353.

/freestage/cue/<uuid>
/freestage/cue/number/<number>
/freestage/cue/go
/freestage/cue/next
/freestage/cue/prev

Right-click any cue and choose Copy OSC Trigger Address.

UI Themes

FreeStage can change the colours of its window chrome (panels, masthead, footer, and monitor borders) to match your studio or personal preference.

  • Open Settings → App Theme and choose a preset from the shared WOODSEE-DIGI swatch collection.
  • Available presets include System Default, Matrix Dark/Light, Cyberpunk Neon Dark/Light, Hello Kitty Pinks, Rainbows and Unicorns, Clean and Minimal, Professional, btop Tokyo Night, btop Nord Dark/Light, btop Solarized Dark/Light, btop One Dark, and btop Monokai.
  • Each theme also sets the app's light/dark appearance, so the whole window stays consistent.
  • The theme is saved automatically and applies to every FreeStage window.
  • The video monitors keep a slightly different background so the Program and Preview outputs remain clearly separated from the chrome.

Note: UI themes change the application chrome, not the graphics inside your show. To change the default colours for lower thirds, bugs, and other template layers, use Settings → Show Style.

Settings

Open Settings with Cmd ,. Open the bundled help from the Help menu or with Cmd ?.

  • Recording: directory, format, bitrate.
  • Show Mode: Record on GO, auto-stop, virtual camera activation.
  • Streaming: manage RTMP destinations and enable the HaishinKit backend.
  • Show Style: choose default colours, fonts, and layout for new template layers, and save your own presets.
  • App Theme: change the FreeStage window chrome and overall light/dark appearance.
  • External Control: HTTP/OSC trigger servers, ports, and localhost-only security.
